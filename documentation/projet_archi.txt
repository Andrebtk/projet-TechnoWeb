La liste des services à implémente :

1 : créer un compte User
méthode -> POST
Exemple d’URL -> http://organiz-asso.com/api/createUser
Fonction -> createUser(...)

2 : login est bon ?
méthode -> POST
Exemple d'URL -> http://organiz-asso.com/api/login
Fonction -> login(...)

3 : tout les messages du forum public
méthode -> GET
Exemple d'URL -> http://organiz-asso.com/api/forumPublic/all
Fonction -> getAllMessages(...)

4 : messages sur le forum (ouvert ou fermé)
méthode -> GET
Exemple d'URL -> http://organiz-asso.com/api/forum/{typeForum}/{userId}/messages
Fonction -> getMessagesUser(userId, typeForum, ...)

5 : Create message sur forum
méthode -> PUT
Exemple d'URL -> http://organiz-asso.com/api/forum/{typeForum}/{userId}/createMessages
Fonction -> createMessageUser(userId, typeForum, ...)
